# Community Connect Hub

Create a clean, modern, minimal website with a simple white design and a professional community-focused feel.

Overall Design

Use a predominantly white background with plenty of whitespace.

Keep the design simple, elegant, trustworthy, and mobile-friendly.

Use clean typography and subtle borders/shadows.

Avoid an overly complicated or flashy design.

Make the website feel like a trustworthy community platform.

Fully responsive for mobile, tablet, and desktop.

All important content should be easy to edit later.

Website Structure

Create these main pages:

Home

About Us

Contact Us

Home Page

The Home page should contain:

1. Header

Clean logo area.

Navigation:

Home

About Us

Contact Us

Add a prominent Join Community / Get Started button.

Keep the header simple and sticky if appropriate.

2. Hero Section

Create a simple, attractive hero section explaining what the community is about.

Include:

Strong headline

Short description

Primary CTA button

Secondary CTA if useful

Space for a main image or community photo

The hero should immediately communicate trust, community, and the value of joining.

3. Community Section

Create a section explaining the community.

Include:

What the community is

Who it is for

Why people should join

Key benefits

A CTA to join/contact through WhatsApp

Make this section visually clean and easy to edit.

4. Related Pages / Services

Create a section displaying related pages, communities, or services.

Use clean cards with:

Image

Title

Short description

View More button

The cards should be editable so I can add, remove, or change pages later.

5. Reviews / Testimonials

Create a prominent Reviews & Testimonials section.

Reviews should be displayed in attractive cards.

Each review should support:

Customer/community member name

Profile photo

Rating

Review text

Optional date

Important:

Make the reviews editable from an admin/content management area.

I should be able to add, edit, delete, and reorder reviews.

Allow image uploads for reviewer photos.

Also include an option to add reviews collected through WhatsApp manually.

6. Photo Gallery / Community Photos

Create a simple photo gallery section.

Allow:

Uploading multiple photos

Adding/removing photos

Reordering photos

Optional captions

The gallery should be easy to manage without changing the website code.

7. FAQ Section

Add a clean accordion-style Frequently Asked Questions section.

Requirements:

Questions expand/collapse.

FAQs must be editable.

I should be able to add new questions.

I should be able to edit existing questions.

I should be able to delete questions.

I should be able to reorder FAQs.

Do not hard-code the FAQ content directly into the UI.

8. WhatsApp CTA

Add WhatsApp contact/join buttons throughout the website where appropriate.

The main CTA should allow users to directly contact the community through WhatsApp.

Make the WhatsApp number configurable so it can be changed later without modifying the entire website.

9. Final CTA

Before the footer, add a strong final call-to-action:

Short headline

Short supporting text

WhatsApp / Join Community button

Footer

Create a professional footer on every page.

Include:

Logo/name

Short description

Quick Links

Home

About Us

Contact Us

Community/related links

WhatsApp/contact information

Social media links

Copyright

Privacy Policy placeholder

Terms & Conditions placeholder

Keep the footer simple and clean.

About Us Page

Create a dedicated About Us page containing:

Hero/header

About the organization/community

Mission

Vision

What makes the community different

Community photos

CTA to join/contact

All major text and images should be editable.

Contact Us Page

Create a dedicated Contact Us page.

Include:

Contact information

WhatsApp button

Phone number

Email

Social media links

Simple contact form:

Name

Phone/WhatsApp number

Email

Message

Submit button

Also include a simple FAQ or help section if appropriate.

Content Management / Editing

Build the website so that content can easily be managed.

I should be able to edit:

Website text

Hero content

Images

Community information

Related pages

Reviews

Reviewer photos

Gallery photos

FAQs

WhatsApp number

Contact details

Social media links

Footer content

Create a simple Admin / Content Management interface where possible.

The goal is that I can manage the website's content without needing to edit the source code.

Technical Requirements

Fully responsive.

Fast loading.

SEO-friendly structure.

Accessible buttons and navigation.

Clean URL structure.

Proper image optimization.

Use reusable components.

Keep the codebase clean and organized.

Use placeholder content/images initially so I can replace them later.

Do not over-design the website.

Prioritize simplicity, trust, community, and ease of management.

Visual Direction

Think of the website as:

Minimal + White + Trustworthy + Community-focused + Modern

Use subtle visual elements rather than heavy gradients, animations, or excessive colors.

The final result should feel like a professional community organization website, not a complicated corporate website.
